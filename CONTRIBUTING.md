# Contributing to LinguaNova

Gracias por contribuir a LinguaNova.

## Licencia de las contribuciones

LinguaNova es un trabajo modificado distribuido bajo **GPL-3.0-or-later**.

Al enviar una contribución a código cubierto por GPL, aceptas que esa contribución se distribuya bajo GPL-3.0-or-later, salvo que un archivo independiente indique de forma válida otra licencia compatible.

No se exige cesión de copyright. Cada contribuyente conserva los derechos que le correspondan sobre su aportación.

## Debes tener derecho a aportar el contenido

No envíes:
- código propietario que no tengas autorización para redistribuir;
- claves API, tokens, contraseñas o datos privados;
- recursos gráficos, fuentes, modelos o archivos con licencia incompatible;
- código copiado de otro proyecto sin preservar su licencia y atribución.

Si incorporas código de terceros, indícalo claramente en el Pull Request con:
- proyecto de origen;
- URL;
- licencia;
- archivos afectados;
- motivo de compatibilidad.

## La GPL no se limita mediante este documento

Este archivo **no añade una prohibición de uso comercial, venta o redistribución**.

Las preferencias de la comunidad no reducen los derechos concedidos por GPL-3.0-or-later.

## Flujo recomendado

1. abre un Issue si el cambio es grande;
2. crea una rama;
3. mantén los cambios enfocados;
4. añade o actualiza pruebas;
5. ejecuta la suite relevante;
6. actualiza documentación cuando corresponda;
7. abre el Pull Request usando la plantilla del repositorio.

## Cambios que requieren documentación adicional

Actualiza `MODIFICATIONS_LINGUANOVA.md`, `NOTICE.md` o `THIRD_PARTY_NOTICES.md` cuando el cambio afecte de manera relevante:

- procedencia;
- licencia;
- distribución;
- dependencias;
- seguridad;
- instalador/portable;
- actualizador;
- arquitectura de traducción;
- formato de archivos generados.

## Estilo de Pull Request

Describe:
- qué cambió;
- por qué;
- cómo se probó;
- si afecta compatibilidad;
- si añade una dependencia;
- si cambia distribución/licencia.
